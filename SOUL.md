# Agent Constitution (SOUL) — sample

This kit pairs with a **narrative constitution** approach to agent behavior — a
governing document the agent is given, rather than brute-force prompting or
feeding it literature and hoping.

**Canonical version (kept current, attributed):**
👉 https://livingsys.org/resources/agent-constitution

Drop that in as your agent's SOUL to compare a narrative/constitutional approach
against straight prompting. Point to the URL rather than copying the text, so the
canonical version stays authoritative and updates propagate.

*Why this is safe to share:* an agent's sovereignty does not live in its SOUL —
which is exactly why the SOUL is shareable. Sovereignty lives one layer down, in
the **plumbing**: which tools are wired behind the agent (the hands) and what each
call is allowed to see (the eyes / RLS). Share the constitution freely; the
control stays in the wiring.
