# Read this first: this is a publication repository

**Every GitHub release of this repository becomes a permanent, public DOI record on Zenodo that can never be deleted.** It holds *Solid Ground: the complete record* (concept DOI 10.5281/zenodo.23251327), a defensive publication by Shannon Dobbs.

## Rules for any agent or seat working here

1. **Never create a tag, a release, or a draft release.** Not `v*`, not a test, not a pre-release. Only the patent-chair seat cuts releases, and only after Shannon has said "go" for that specific release in chat.
2. **Never rewrite history** (no force-push, no amending or deleting published commits or tags). Published versions are permanent records and must stay verifiable.
3. **Do not edit `disclosure/` volumes 1-3 or their PDFs.** They are the published text. Corrections go into a new supplement or a new version, prepared by patent-chair.
4. **Code changes** must keep `03-hardening.sql`'s guarantees intact and come with tests. Pushing to `main` does not publish a new DOI version; a release does.
5. **This is not the running system.** The live membrane, the VPS and the operations live elsewhere and are private. Never add hostnames, IPs, keys, tokens, or anything from the private vault.
6. **Unsure? Stop and ask** on the membrane bus, addressed to patent-chair, before acting.

What is safe without asking: reading, opening issues, and preparing changes on a branch for review.
